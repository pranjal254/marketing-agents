What each agent is built with

# Agent AI Brain What else is needed to build it AI Cost / Campaign
1 Campaign Identification
(turns requests into approved briefs)		 Claude Sonnet 5 (the fast, efficient model) Built as a standalone Python agent using the Claude Agent SDK, connected to Microsoft Forms, Excel and OneDrive so it can read requests and write the brief as a Word document. Once built and tested, it is onboarded to Execution Studio to run. ~$0.05
2 Campaign-in-a-Box Orchestrator
(plans the campaign, then packages it)		 Claude Opus 5 (the premium model, for the deep planning work). The packaging step uses plain automation logic, no AI needed Built as a standalone Python agent, connected to SemRush (market and competitor data), OneDrive (content library search), and Word/Excel (calendar, checklist, workspace). Onboarded to Execution Studio once ready. ~$0.65
3 Content Repurposing
(writes the flagship, spins out 8 channel versions)		 Claude Opus 5 (premium model, because writing quality is the product here) Built as a standalone Python agent, connected to Word and OneDrive for versioned drafts. Bulk-processing mode is used for the 8 spin-off versions, which halves the AI cost of that step. Onboarded to Execution Studio once ready. ~$3.00
4 Collaboration & Iteration
(gathers reviewer comments, applies agreed edits)		 Claude Sonnet 5 Built as a standalone Python agent, connected to Word (reads everyone's comments, applies tracked changes) and Excel (updates the status tracker). Sends reviewer reminders automatically. Onboarded to Execution Studio once ready. ~$0.45
5 Quality Gate & Approval
(checks brand rules, routes sign-offs)		 Simple rule-checking code for the black-and-white rules (free, instant), plus Claude Sonnet 5 only for judgment calls like tone and meaning Built as a standalone Python agent: a rules checker, plus workflow logic that assigns review tasks, sends reminders, records every approval and locks the finished package in OneDrive. Onboarded to Execution Studio once ready. ~$0.35
